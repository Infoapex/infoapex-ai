# ICM-01 — planner-to-worker traceability

Status: implemented and reviewed locally on 2026-08-28.

## Outcome

- Planner gates now declare explicit `criterionIds`; naming/position inference is gone.
- Planner compile emits worker contract v1.1 with lossless task `traceability`.
- Worker manifest v1.1 preserves criterion IDs, gate IDs, evidence contracts and links,
  while legacy plans without `workerContractVersion` remain on v1.0.
- Planner and worker reject duplicate, dangling, uncovered and drifted mappings.
- Fake, Codex and Claude task evidence paths emit evidence v1.1 for traceable tasks.
- Independent review receives stable criterion IDs from the frozen manifest.
