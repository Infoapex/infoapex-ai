# ICM-03 - deterministic compiler and worker integration

Status: implemented and validated locally on 2026-08-28.

## Outcome

- AI Code Control compiles a strict `context-package.v1` from a frozen worker
  manifest through the `context-compile` JSON CLI boundary.
- Selection is deterministic: declared task inputs, file-backed evidence contracts,
  then exact codegraph symbol ranges. Sources are included whole or explicitly
  omitted; no source is silently truncated to satisfy the budget.
- The compiler normalizes content and ordering, redacts secret-like values, rejects
  unsafe paths and links, and emits provenance plus a semantic SHA-256 digest.
- The worker independently validates the schema and digest, exports per-task packages
  and an index, and supports `off`, `observe`, and fail-closed `enforce` modes.
- Codex and Claude consume the validated package in enforce mode and append a
  `task.context-compiled` event that links task, package, digest, and consumption.
- Explicit `--repo` handling now allows the control CLI to address a module-local
  configuration from the enclosing monorepo.

## Measurement

The preregistered range was 3.0M / 4.1M / 5.2M reported tokens. Actual usage was
15,460,481 tokens, 277.08% above the median and outside the range (RED). The rate-limit
window reset during the stage and the reported percentage moved from 44% to 0%, so
tokens-per-percentage-point is correctly classified as NOT_COMPARABLE. No parallel
Codex sessions were detected.

This result indicates estimation drift for an integration stage spanning three
modules and full validation, not a functional failure. Future stages retain their
preregistered estimates until at least three clean comparable samples exist.

## Residual risk

The older optional context-provider health/brief/impact response shapes remain
different from the module-native control CLI shapes. Context-package compilation is
covered by the new strict boundary and works independently; modernizing the legacy
adapter is deliberately outside ICM-03 scope.
