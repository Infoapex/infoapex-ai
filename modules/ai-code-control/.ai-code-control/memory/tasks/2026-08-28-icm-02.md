# ICM-02 - deterministic context package contract

Status: implemented and reviewed locally on 2026-08-28.

## Outcome

- AI Code Control now owns strict `context-package.v1` schema and an engine-neutral
  example artifact.
- The Core library exposes typed contract records, strict JSON serialization, semantic
  validation, canonical SHA-256 computation, and digest drift detection.
- The digest is stable across package instance IDs, timestamps, and collection order.
- Absolute checkout paths, file URIs, backslashes, and parent traversal are rejected.
- Token budgeting is primary; character budgeting is available only as an explicit
  fallback. Included and omitted source sets cannot overlap.
- ADR-0010 records ownership, compatibility, and invalidation semantics.

## Measurement

The preregistered range was 2.8M / 3.8M / 4.8M reported tokens. Actual usage was
3,602,898 tokens, -5.19% from the median and inside the range (GREEN). The clean 17
percentage-point delta maps to 211,935 tokens per point. One clean sample is not enough
to refit future estimates; the three-sample minimum remains in force.
