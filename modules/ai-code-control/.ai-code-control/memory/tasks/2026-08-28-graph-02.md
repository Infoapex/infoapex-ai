# GRAPH-02 - deterministic trace ingestion and entity resolution

Status: implemented and validated locally on 2026-08-28.

## Outcome

- `TraceGraphIngestService` reads only an explicit document list and has no LLM path.
- Supported inputs are ADRs, JSON contracts, planner plans, ICM source maps, ICM context
  packages, and strict `trace-relations.v1` sidecars.
- The code index contributes file and fully-qualified symbol nodes. Simple symbol names
  resolve only with exactly one candidate; ambiguous and missing names remain unresolved
  diagnostics, never first-match selections.
- ICM relations are mapped into the accepted graph vocabulary with explicit direction:
  requires to depends_on, implemented_by to reversed implements, and changed_by to
  reversed changes.
- Node authority is persisted. Proposed decisions and sources remain proposed and cannot
  be mistaken for accepted canonical decisions.
- Duplicate descriptions of a stable identity are merged through deterministic authority,
  origin, and title precedence, with provenance diagnostics.
- Contracts and plans use canonical JSON hashes; source maps and context packages prefer
  semantic digests. A repository commit change alone does not rewrite unchanged entities.
- `trace-relations.v1` provides a strict declared T1 sidecar contract with direct evidence
  and no automatic caused relation.
