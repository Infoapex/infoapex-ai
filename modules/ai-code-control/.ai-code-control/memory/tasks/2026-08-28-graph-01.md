# GRAPH-01 - temporal trace schema and repository API

Status: implemented and validated locally on 2026-08-28.

## Outcome

- Code graph schema version 3 adds temporal `trace_nodes`, `trace_edges`, current-state
  indexes, and `trace_ingest_runs` without changing the structural code `edges` table.
- Schema setup is idempotent and migration version markers are written only after the
  corresponding structures and compatibility column/index complete successfully.
- Stable node IDs hash namespace plus canonical ref; display-title and property-order
  changes cannot change identity.
- `TraceGraphRepository` supports idempotent temporal upsert, current and history reads,
  compare-and-invalidate by source commit, and transactional full rebuild.
- Repository validation and SQLite constraints both enforce node/edge vocabulary,
  origin/tier/confidence alignment, evidence refs, canonical JSON properties, and valid
  temporal intervals. Automatic `caused` is impossible through the supported schema.
- File canonical refs and evidence refs reject absolute host paths. Changes must move
  forward in time, source identity ownership is unique, endpoints must resolve, and a
  source cannot be invalidated if that would orphan another source's current edge.
- Full rebuild accepts cross-source endpoints, is independent of input/property order,
  and produces a deterministic current-state digest.
