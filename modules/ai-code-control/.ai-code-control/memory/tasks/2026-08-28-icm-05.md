# ICM-05 - semantic source maps and glass-box enforcement

Status: implemented and validated locally on 2026-08-28.

## Outcome

- Traceable worker-contract v1.1 runs generate a strict, digest-protected
  `source-map.v1.json` before `run.done`.
- Stable nodes cover context sources, contracts/decisions, criteria, tasks, symbols,
  changed files, commits, gates, evidence, and context packages.
- The only machine relations are `selected_for`, `requires`, `implemented_by`,
  `changed_by`, `verified_by`, and `derived_from`; automatic `caused` edges are not
  representable by the schema.
- Every edge identifies declared, observed, or deterministically derived confidence
  and the artifact references that support it.
- Criterion and gate IDs must round-trip into evidence. Every PASS criterion requires a
  linked command with exit code zero; missing/non-passing evidence blocks DONE.
- Proposed sources can remain selected advisory context but cannot participate in a
  `verified_by` edge or authorize a verdict.
- The source-map digest excludes creation time, is stable across discovery order, and
  is recomputed immediately before persistence.
- A `source-map.generated` event records digest and trace coverage.

## Validation

- AI Code Planner: 35/35 tests PASS and 18 JSON files valid.
- AI Code Control: 69/69 tests PASS.
