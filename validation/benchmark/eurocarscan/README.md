# EuroCarScan consumer benchmark

This is a private-manifest consumer cohort for the greenfield EuroCarScan
repository. The suite stores prompts and evaluator-only file assertions; the
repository under test is supplied at runtime and is never copied into this
benchmark repository.

The first cohort is a bounded BENCH-P-shaped pilot: ten paired tasks, one
repetition, and three arms. It is not a public ranking and must be run only
after the experiment and provider authorization have been frozen.
