# Security policy

Infoapex AI is pre-release. Report vulnerabilities privately to the repository owner;
do not include secrets, customer source, or raw provider transcripts in an issue.

The supported `core-local` boundary is one explicitly authorized local repository.
External actions and telemetry export are disabled by default. Plans, logs, diagnostics,
and evidence must contain references or redacted summaries rather than secret values.

Critical/high findings, scope escapes, secret leakage, invalid signatures, and
destructive recovery cannot be waived for a production release.
